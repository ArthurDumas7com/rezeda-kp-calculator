# Сервер данных договоров

Этот компьютер хранит справочники **Исполнителей** и **Заказчиков** и раздаёт их
другим устройствам — телефону, ноутбуку, компьютеру коллеги. Юридические данные
вводятся один раз, кнопка «Сохранить» кладёт их сюда.

## Запуск

Кнопка и данные лежат **рядом с папкой проекта**, в отдельной папке:

```
ME\CloudeCode\
  КП автоматизация Резеда - сервер\     ← кнопка и данные
    Запустить сервер данных.cmd
    dogovor-data.json
  CP for VIS ARCH\                      ← сам проект (репозиторий)
```

Двойной клик по **«Запустить сервер данных.cmd»**. Откроется окно с адресами:

```
На этом компьютере:  http://localhost:8765/
С других устройств:  http://192.168.1.50:8765/
```

Окно можно свернуть — пока оно открыто, данные доступны. Закрыли окно —
сайт продолжает работать, но общие справочники становятся недоступны.

При первом запуске Windows спросит про доступ к сети — нужно разрешить для
**частных сетей**. Без этого другие устройства сервер не увидят.

## С другого устройства

Устройство должно быть в той же сети (тот же Wi-Fi). Откройте в браузере адрес
вида `http://192.168.1.50:8765/` — сайт и справочники загрузятся с этого
компьютера. Адрес меняется, если роутер выдаст компьютеру другой IP; в этом
случае просто посмотрите новый адрес в окне сервера.

Если сайт открыт **файлом с диска** (не по ссылке), адрес сервера указывается
вручную — поле «Адрес сервера данных» в правой панели вкладки «Договор».

## Где лежат данные

```
..\КП автоматизация Резеда - сервер\dogovor-data.json
```

Намеренно **вне папки проекта**: репозиторий публичный, а это ИНН, паспорта и
банковские реквизиты. В коде приложения справочников нет — только пустые
`PRESET_EXECS` / `PRESET_CLIENTS`. Рядом сервер держит `.bak` — копию
предыдущей версии файла.

Резервная копия вручную: кнопка «Экспорт» в правой панели.

## Что работает без сервера

Всё, кроме общих справочников: расчёт КП, заполнение договора, Word и PDF.
Браузер хранит свою копию справочников и черновик, поэтому на своём устройстве
вы продолжаете работать как обычно. Изменения, сделанные без сервера, уедут на
него по кнопке «Синхронизировать», когда он снова будет включён.

## Необязательные настройки

| Переменная | Зачем |
|---|---|
| `REZEDA_PORT` | другой порт, если 8765 занят |
| `REZEDA_TOKEN` | требовать ключ доступа (заголовок `X-Rezeda-Key` или `?key=`) |
| `REZEDA_DATA_DIR` | другая папка для файла данных |

Пример: `set REZEDA_PORT=8080` перед запуском.

**Про безопасность.** По умолчанию доступ открыт всем в локальной сети без
пароля — этого достаточно для домашней или офисной сети. Не пробрасывайте порт
наружу через роутер: данные передаются по http, без шифрования.

## Автозапуск вместе с Windows

Нажмите `Win+R`, введите `shell:startup`, положите в открывшуюся папку ярлык на
`data-server.cmd`. Сервер будет подниматься при входе в систему.
